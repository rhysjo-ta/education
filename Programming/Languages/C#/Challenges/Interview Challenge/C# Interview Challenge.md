**Objective**

* Create a **Console app**
* From google.co.uk, automate navigation to Top Sellers games on steam
* Scrape info on top 20 games:

&nbsp;	 - Name

&nbsp;	 - Release Date

&nbsp;	 - Any other useful information (e.g. href)

* Serialise data into JSON array
